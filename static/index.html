HONEST ABOUT THE PILOT

Local roots first.

  • No login or access control. Anyone using this device can access and change this pilot.
  • Breeze is disconnected. An optional person ID is stored locally. No sync, API keys, or provider requests.
  • First visit is once ever. Mark returning teens when registering. Staff must verify who brought the friend; the software cannot prove the relationship.
  • Redemption is phase 2. This pilot awards points and records prize drawings. No store, checkout, or spending.
  • Corrections are phase 2. Saved check-ins are locked. An audited compensating-entry workflow is required before real operations.

Only available in an empty database. Use a separate empty database to test without fixtures. Real youth records require production safeguards.
